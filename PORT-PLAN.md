# The Fortran port: scope freeze and test ladder

*(Eighty-second push. This document ends the decode-first phase: from here the default
work is porting, and decode rounds happen only when a port gate demands one.)*

## The scope, frozen (v0.1)

**In scope**: closed-shell neutral molecules of H, C, N, O, F (+He as a calibration
element). Eigenvalue spectra and the decoded energy layers. Everything the six-system
gate + the C/N scope gate validated:

| system | worst |d| (all) | occupied-only | status |
|---|---|---|---|
| H2 | 0.010 | 0.010 | PASS |
| F2 | 0.039 | 0.039 | PASS |
| HF | 0.032 | 0.032 | PASS |
| H2O | 0.088 | 0.033 | LUMO only (grand-law re-fit pending) |
| CH4 | 0.057 | 0.057 | 0.007 over, one uniform shift (C-H pairs unmeasured) |
| NH3 | 0.157 | **0.027 PASS** | virtuals = the known water-LUMO class |
| H3+ / HeH+ | — | — | ions: HeH+ PASSES; carried as labeled extras |

**Out of scope for v0.1, carried as labeled open items** (each has a bank anchor):
the ES3 Fock shortcut (ion-only defect), the ss off-diagonal law, the k_p metric
puzzle, µ-CN radii for unmeasured pairs, dispersion (revD4 pass-through), open-shell.

## The architecture rule the port must keep

**The energy and the Fock are separate objects** (T1; measured twice — exchange and
ES3). The port implements the *measured* Fock (what the binary applies) and the
*decoded* energies (what the binary prints), and never assumes one is the derivative
of the other. Gradients, when they come, differentiate the IMPLEMENTED Fock.

**No method constants in code.** Every number loads at start from two files: the
pristine parameter file (`gxtb_parameters`) and the derived-constants export
(`fortran/data/derived.dat`, generated by `prototype/export_fortran.py` from
`derived-constants.json` — regeneration is part of the build, hand-editing is not).

## The test ladder (each unit gates against banked python numbers before the next)

- **U1 — parameters + element laws** (`gxtb_param.f90`, `gxtb_elem.f90`): parse the
  parameter file; compute k = L4, kb = kb_scale·L8[3], kdiat, c_x = s_rule/9.59, U, µ,
  L2, L5 per element. Gate: match `elem-reference.dat` (python `elem()`) to 1e-10.
- **U2 — basis + overlap**: q-scaled contractions, S and S̃ vs banked matrices.
- **U3 — H0 assembly**: the full off-diagonal law vs python H0 (H2/F2/HF/H2O).
- **U4 — ACP**: analytic V·diag(c)·V^T vs `f2_stretch.acp_matrix`.
- **U5 — potential + SCF**: the unified Mulliken potential (µ, γ2-onsite, KO-offsite,
  X, ES3-v1) + grand short pieces; gate = the six-system eigenvalue table above.
- **U6 — energies**: repulsion, ES1/ES2+3, EHT+ACP, Ex; gate = the banked energy-gate
  numbers (H2 end-to-end; F2/HF per-term).
- **U7 — tblite integration**: wire as `src/tblite/gxtb/` behind tblite's calculator
  interface; meson build; the ladder's gates re-run through the library entry point.
- **U8 — gradients**: differentiate the implemented Fock (T1's rule).

`fortran/` at the repo root is the staging ground for U1–U6 (plain gfortran, no build
system); U7 moves it into `src/tblite/` proper.
